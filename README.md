# CongoImmo Backend

Backend Node.js + Express + MongoDB Atlas pour la plateforme immobilière CongoImmo.

## Technologies

- Node.js
- Express
- MongoDB Atlas
- Cloudinary
- JWT Authentication
- Render

## Installation

npm install

## Lancement local

npm start

## Variables d'environnement

Créer un fichier .env :

PORT=
MONGO_URI=
JWT_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
